      3개 배치 안 및 설계 근거 비교
      
    
        
  • 안 A (프로필+탭, 권장): 상단에 ActivityPub 프로필을 두고 탭으로 타임라인과 지식 베이스 개요를 전환합니다. 개인 KB가 비공개(is_public=0)일 때도 동일한 상단 프로필과 공개 Note 타임라인이 자연스럽게 유지되며, 첫 화면 스크롤 밀도가 가장 균형적입니다.
    • 
        
  • 안 B (프로필+2열 병렬): 넓은 화면(@container home (min-width: 820px))에서 타임라인과 KB 핵심 지표를 동시에 봅니다. 단, 문서 문맥 패널이나 좌측 목록을 동시에 열면 컨테이너 폭이 줄어 1열로 접힙니다.
    • 
        
  • 안 C (기존 개요 통합): 기존 #homewrap의 지식 맵·최근 적재 카드를 주 화면으로 두고 타임라인을 카드 하나와 <details>로 접어 넣습니다. ActivityPub 정체성이 다소 약합니다.
    • 
        
  • 점선 표기 (제안): FEDERATION.md §4.1 기준 현재 Person 문서에 없는 summary(소개글) 필드는 점선 테두리와 제안 칩으로 구분했습니다.
