2안: 시나리오 워크벤치 · 비교진입점 카드 런처 + 분해 보드 + 경로 1:1 diff 표 + 5관문·자막 규칙 시뮬레이터진입점 간 차이(diff)와 5관문·자막 우선순위 규칙을 직접 손으로 체험하며 이해하기 좋음초기 방문자에게는 정보 밀도가 다소 높을 수 있음
3안: Hindsight 참조 (4열 라이브 흐름)고정 4열 공간 SVG(입력 → 처리 엔진 → SQLite 실린더 → 비동기 워커) + 진행률 밑줄 탭 + 재생/배속/전체화면 + 클릭 점프예시 데이터가 4열을 따라 실시간으로 변하는 모습을 보며 동기/비동기 경계와 저장 구조를 직관적으로 파악좁은 모바일에서는 4열 SVG가 가로 스크롤되며 전체화면(확대) 버튼 활용이 중요
4안: Gemini Neon (통합 5단계 광학 프리즘)진입점 선택지 제거 + favicon.svg 에메랄드·애저 네온 광학 캔버스 + 5단계 신호 레일 + 서버 API/에이전트 단일 토글 + 표본 변형 & 4단계 내장 5관문 게이지진입점 구분으로 인한 선택 과부하를 없애고 문서 1편이 raw_text→추출/정리본→5관문→그래프로 변환되는 핵심 생애주기를 직관적으로 전달특수 진입점(예: 텔레그램 복합 2배 예산, 3종 백그라운드 루프) 세부 규칙은 2차 아코디언에 접어 둠
