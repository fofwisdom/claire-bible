# Upstream Documentation (`docs/upstream/`)

이 디렉터리는 원작 저장소(**업스트림: [`blackan/claire_bible`](https://github.com/blackan/claire_bible)**)의 `docs/` 디렉터리에 포함된 원본 문서들을 분리 보관하는 공간입니다.

---

## 1. 개요 및 목적
- 업스트림 프로젝트의 원본 설계, 아이디어 리서치, 초기 명세를 변경 없이 참조용으로 보존합니다.
- 오리진 프로젝트([`fofwisdom/claire-bible`](https://github.com/fofwisdom/claire-bible))에서 자체 작성하거나 개정/병합한 문서는 [`docs/origin/`](../origin/README.md)에 보관합니다.
