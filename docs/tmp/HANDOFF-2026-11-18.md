```bash
tar -xzf ~/claire-bible-handoff-2026-11-18.tar.gz
```

## 3. 새 컴퓨터에서 시작

```bash
git clone https://github.com/fofwisdom/claire-bible.git
```

```bash
uv sync
```

단위 시험:

```bash
PYTHONPATH=$PWD/src .venv/bin/python -m pytest -n 4 -p no:cacheprovider --basetemp=/tmp/ckb tests
```

시험 뒤 `/tmp/ckb`, `/tmp/pytest-of-*`를 지운다(`/tmp`는 작은 tmpfs). Playwright E2E는 `scripts/e2e.sh`로만 실행한다(전체 약 6.5분, 8분을 넘으면 결함).
