Claire Bible vocabulary

Claire Bible servers use these terms when they exchange shared knowledge with ActivityPub. The terms are for Claire Bible only.

Namespace: https://w3id.org/claire-bible/ns# (prefix claire). JSON-LD context: https://w3id.org/claire-bible/ns/v1. The context of version 1 does not change. A new term goes to a new version: version 2 (https://w3id.org/claire-bible/ns/v2) has the terms of version 1 and the terms of renditions and +1.

A document uses this context together with the ActivityStreams context https://www.w3.org/ns/activitystreams. The terms Grant, Revoke, and capability have the identifiers of the ForgeFed vocabulary (https://forgefed.org/ns#). Claire Bible claims no conformance to ForgeFed.

Types

TermIdentifierBase typeSinceDefinition
claire:KnowledgeBasehttps://w3id.org/claire-bible/ns#KnowledgeBaseGroupv1A shared knowledge base: a knowledge base that has no owner, that is always public, and that accounts build together. It is an actor. Servers that hold copies of its documents follow it.
claire:Extractionhttps://w3id.org/claire-bible/ns#ExtractionObjectv1The entities and the relations that a server found in one document. A receiver builds its graph from them and does not send the document to a language model.
claire:Contributionhttps://w3id.org/claire-bible/ns#ContributionObjectv1One document with its extraction that an account offers to one shared knowledge base.
Granthttps://forgefed.org/ns#GrantActivityv1An activity that gives a role in a resource to an actor until an end time. The term is the one of the ForgeFed vocabulary. In Claire, a shared knowledge base gives the role claire:collaborator to an account of another server.
Revokehttps://forgefed.org/ns#RevokeActivityv1An activity that ends a grant immediately. The term is the one of the ForgeFed vocabulary.
claire:RenditionBodyhttps://w3id.org/claire-bible/ns#RenditionBodyObjectv2The body of a rendition: the compiled HTML in "content" and the AsciiDoc text in "source". The origin gives it only to the server actor of another Claire server, with a valid HTTP signature.
claire:PlusOnehttps://w3id.org/claire-bible/ns#PlusOneActivityv2A +1 of an account for a rendition. Only Claire servers send it and read it.

Properties

TermIdentifierSinceDefinition
claire:knowledgeTypehttps://w3id.org/claire-bible/ns#knowledgeTypev1The knowledge type of a shared knowledge base: "real" for knowledge about the real world, or "fictional" for knowledge about an invented world.
claire:documentCounthttps://w3id.org/claire-bible/ns#documentCountv1The number of visible documents in a shared knowledge base.
claire:entityCounthttps://w3id.org/claire-bible/ns#entityCountv1The number of entities in a shared knowledge base.
claire:relationCounthttps://w3id.org/claire-bible/ns#relationCountv1The number of relations in a shared knowledge base.
claire:signaturehttps://w3id.org/claire-bible/ns#signaturev1The subject signature of a shared knowledge base, as one JSON value. The key "entities" has at most 256 rows [type, norm_name, weight]: the entities that the most documents have. The key "visible_documents" is the number of documents that were counted. The key "computed_at" is the time of the calculation. A server compares signatures to put knowledge bases with the same subject in one theme.
claire:documentshttps://w3id.org/claire-bible/ns#documentsv1The collection of the documents of a shared knowledge base.
claire:contentHashhttps://w3id.org/claire-bible/ns#contentHashv1The SHA-256 of the source text of a document, as 64 lowercase hexadecimal characters. A different value for the same document is a revision.
claire:roothttps://w3id.org/claire-bible/ns#rootv1The root document: the document from which a chain of copies started. Revisions come from it. A root document refers to itself.
claire:extractionhttps://w3id.org/claire-bible/ns#extractionv1The extraction of a document.
claire:keyClaimshttps://w3id.org/claire-bible/ns#keyClaimsv1The main statements of a document, as plain text, in sequence.
claire:entitieshttps://w3id.org/claire-bible/ns#entitiesv1The entities of an extraction, as one JSON array. Each entity has the keys "name", "type", "norm_name" (the name in its normal form; "type" and "norm_name" together are the key of the entity), "aliases", and "observations". The key "sameAs" is optional: identifiers of the same thing at an authority, for example "wd:Q42" (Wikidata), an ISBN, or an ORCID. The key "proposed_type" is optional.
claire:relationshttps://w3id.org/claire-bible/ns#relationsv1The relations of an extraction, as one JSON array. Each relation has the keys "source" and "target" (each one the "name" of an entity of the same extraction) and "type". The key "proposed_type" is optional.
claire:documenthttps://w3id.org/claire-bible/ns#documentv1The document of a contribution.
claire:reasonCodehttps://w3id.org/claire-bible/ns#reasonCodev1The reason of the reviewers for a rejection or a removal: "off_subject", "wrong_knowledge_type", "duplicate", "low_quality", "spam", or "other". A rejection of an automatic contribution can also have "automatic_not_accepted": the server of the knowledge base accepts no automatic contributions now. A rejection of a contribution can also have "limit_reached": the contributions of the account or of its server that wait for a decision are at a limit of the server of the knowledge base now. With these two values the account can offer the document again later.
claire:automatichttps://w3id.org/claire-bible/ns#automaticv1true in a contribution that the automatic rule of the account selected. A server that accepts no automatic contributions rejects such a contribution. A contribution without this term is one that the account selected itself.
claire:acceptsAutomatichttps://w3id.org/claire-bible/ns#acceptsAutomaticv1true when the server of a shared knowledge base accepts automatic contributions now, false when it rejects them. A server reads it before it sends an automatic contribution.
capabilityhttps://forgefed.org/ns#capabilityv1The grant that permits an activity. The term is the one of the ForgeFed vocabulary. In Claire, an offer of a remote collaborator refers to its grant.
claire:renditionhttps://w3id.org/claire-bible/ns#renditionv2The rendition of a rendition body.
claire:renditionOfhttps://w3id.org/claire-bible/ns#renditionOfv2The document object of a rendition that is not the primary rendition. The document object is also the primary rendition.
claire:renditionshttps://w3id.org/claire-bible/ns#renditionsv2The ordered collection of the published renditions of a document, the primary rendition first.
claire:templatehttps://w3id.org/claire-bible/ns#templatev2The rendition template of a rendition: "standard", "concise", or "academic". A new template is a new value; a value never changes its meaning.
claire:templateVersionhttps://w3id.org/claire-bible/ns#templateVersionv2The version of the rendition template of a rendition, for example "standard-v1". "pre-template" is a body that was made before the templates and counts as "standard".
claire:sourceKeyhttps://w3id.org/claire-bible/ns#sourceKeyv2The SHA-256 of the source identifier of a document (a DOI, an arXiv address, or a normalized web address), as 64 lowercase hexadecimal characters. Documents with the same key have the same source.
claire:sourceIdVersionhttps://w3id.org/claire-bible/ns#sourceIdVersionv2The version of the rules that made the source identifier of a source key.
claire:bodyhttps://w3id.org/claire-bible/ns#bodyv2The address of the body of a rendition (a claire:RenditionBody).
claire:bodyHashhttps://w3id.org/claire-bible/ns#bodyHashv2The SHA-256 of the AsciiDoc text of a rendition body, as 64 lowercase hexadecimal characters. A reader compares it before it gets the body again. It is not claire:contentHash, which is the hash of the source text.
claire:plusOneshttps://w3id.org/claire-bible/ns#plusOnesv2The collection of the +1 marks of a rendition, with "totalItems", claire:servers, and claire:score.
claire:servershttps://w3id.org/claire-bible/ns#serversv2The number of servers of the accounts that gave a +1 to a rendition.
claire:scorehttps://w3id.org/claire-bible/ns#scorev2The +1 count of a rendition with the limit for one server.

Values

TermIdentifierSinceDefinition
claire:collaboratorhttps://w3id.org/claire-bible/ns#collaboratorv1The role of an account whose contributions to a shared knowledge base need no approval.
