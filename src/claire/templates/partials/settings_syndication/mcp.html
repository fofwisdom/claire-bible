🧩 MCP 서버 (/mcp) 구현됨서버 전역

외부 AI 하네스(Claude Desktop · Claude Code · Gemini · Cursor 등)가 지식베이스를 읽는 표준 엔드포인트입니다. claire_api 프로세스 안에서 Streamable HTTP(stateless, JSON 응답)로 동작하며, 도구 10종은 모두 SQLite · FTS5 조회만 해서 LLM 쿼터를 쓰지 않습니다. 이 화면에서 구현됨은 현재 코드 그대로, 제안은 아직 없는 기능입니다.

엔드포인트 · Discovery 미인증 호출은 401 + WWW-Authenticate: Bearer … resource_metadata=…로 응답합니다. DNS 리바인딩 방어로 public_url 호스트와 localhost만 허용하므로 테마 전용 FQDN으로는 접속되지 않습니다.
/.well-known/oauth-protected-resource · /.well-known/oauth-authorization-server
테마 지정 모든 도구가 theme 인자(번호 또는 레이블)를 받고, 생략하면 Theme 0을 읽습니다. REST와 달리 X-Claire-Theme 헤더와 테마 전용 FQDN은 MCP 도구에 적용되지 않습니다. 오른쪽은 상단에서 고른 테마를 읽는 호출 예시입니다.

🔐 인증 채널 구현됨

한 요청에는 인증 채널을 하나만 씁니다(Bearer · X-Session · 쿠키). 익명 접근은 CLAIRE_ANONYMOUS_READONLY와 관계없이 /mcp에서 항상 거부되고, Cross-Origin 요청은 Bearer만 허용됩니다.

엔드포인트 URL만 입력하면 Discovery → DCR → 승인 화면으로 이어집니다. 승인 화면에서 ✅ 바로 승인하기 또는 텔레그램 승인을 누릅니다.

        
저장소의 기존 예시(MCP_SUPPORT.md의 server-fetch, claire token create 출력의 server-everything)는 원격 HTTP 서버 연결 방식이 아니어서 위 형식으로 교체를 제안합니다.
