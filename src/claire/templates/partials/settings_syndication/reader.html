📖 리더 및 목록 스타일 환경설정

작업 공간 탭(연합 클라이언트 · 지식베이스)의 기본값, 두 탭에 공통 적용되는 목록 스타일과 3단/2단 분할, 그리고 하나의 컨텐트 뷰 안에서의 수집 원문 ⇄ 적재 본문 기본 전환 동작을 제어합니다. 변경 사항은 즉시 저장되어 /syndication에 반영됩니다.

기본 작업 공간 탭 (App Tab) 탑바 밑 탭 메뉴에서 처음 열릴 탭입니다. /syndication?tab=client 또는 ?tab=kb로 직접 지정할 수도 있습니다.
기본 목록 스타일 (List Style) 목록은 34px 한 줄 행, 조밀하게는 요약 없이 제목·메타·태그만, 일반은 요약 2줄 미리보기 카드, 넓게는 요약 전체(적재 항목은 Claire 적재 요약 포함)를 표시합니다. 리더에서 l 키로 순환 전환합니다.
기본 화면 분할 구조 (UI Layout) 3단 분할 뷰는 좌측 트리 | 중앙 목록 | 우측 전용 리더 창으로 구성되며, 2단 상하 분할 뷰는 좌측 트리 | 상단 목록 / 하단 리더 창으로 구성됩니다.
제목과 작성자 우측의 남는 가로 영역에 — 본문 첫 문장 미리보기를 말줄임표와 함께 아름답게 배치합니다.
컨텐트 뷰 초기 표시 탭 (수집 원문 vs 적재 본문) 하나의 수집 항목이 수집 원문과 적재 본문을 모두 보유할 때 리더가 우선 노출할 본문 탭을 지정합니다.
리더 본문 서체 (Typography) 긴 아티클 정독을 위한 본문 기본 서체(Noto Sans KR 고딕 / Noto Serif KR 명조)를 선택합니다.
리더 기본 글자 크기 (Font Size) .doc-content 본문 영역의 기본 글자 크기(13px ~ 20px)를 지정합니다.
목록 행·카드·게시물을 클릭하거나 j/k 단축키로 이동할 때 안읽음 표시를 자동 해제합니다.
