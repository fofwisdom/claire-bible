🕸️ WebMCP — /syndication 페이지 도구 제안 · 미구현

WebMCP(W3C Web Machine Learning CG, Draft Community Group Report 2026-10-27)는 페이지가 document.modelContext.registerTool()로 도구를 등록하고, 브라우저 내장 · 확장 에이전트가 사용자가 열어 둔 탭 안에서 호출하는 방식입니다. 추가 토큰 없이 현재 세션으로 동작하고, 같은 출처(same-origin) 문서에만 보이며, 탭을 닫거나 등록 신호를 abort하면 사라집니다. 저장소에는 아직 관련 코드가 없습니다.

WebMCP 도구 등록 (전역) 끄면 /syndication이 도구를 등록하지 않고, 서버가 Permissions-Policy: tools=()를 보내 페이지 안의 다른 스크립트도 등록할 수 없게 합니다. 현재 Claire는 Permissions-Policy 헤더를 보내지 않습니다.
이 테마에서 노출
등록 방식 사양이 정의하는 것은 명령형 registerTool()뿐입니다. 폼 속성(toolname · tooldescription · toolautosubmit)으로 + 구독 폼을 도구로 노출하는 선언형은 explainer 제안 단계라 실험 옵션으로만 둡니다.
사용자 확인 정책 사양에는 도구가 사용자 확인을 요청하는 API가 없습니다(README의 미해결 과제). 그래서 확인이 필요한 도구는 execute() 안에서 페이지 자체 확인 창을 띄워 응답을 기다리고, consequentialHint를 붙여 에이전트 쪽 확인도 유도합니다. 쓰기와 외부 발행은 정책과 관계없이 항상 확인합니다.
에이전트 활동 표시 toolactivated · toolcancel 이벤트를 받아 리더 하단 상태 표시줄에 🕸️ 에이전트: kb_ingest_item 실행 중처럼 표시하고 작업 기록에 남깁니다.

🧰 페이지 도구 목록

작업 공간 탭 범위가 맞는 도구만 등록됩니다(예: client_*는 연합 클라이언트 탭이 열려 있을 때). 연합 게시물이나 수집 원문처럼 제3자 콘텐츠를 돌려주는 도구에는 untrustedContentHint를 붙입니다. 비공개 테마에서는 외부 서버에 반영되는 도구가 등록되지 않습니다.
