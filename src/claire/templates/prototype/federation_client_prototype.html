각 안의 설명

N1 왼쪽 레일에 두 작업공간(🌐 연합 클라이언트, 📚 적재 관리)과 흐름. 미읽음·대기 수가 레일 배지로 보입니다. 키 g c / g k.

N2 상단이 설계 §1.3의 세 단계(수집 → 적재 → 게시)입니다. 단계를 누르면 해당 보기로 갑니다. "게시" 단계는 적재 관리 보기의 미게시·게시됨 필터입니다.

N3 두 보기를 나란히 둡니다. 게시물을 오른쪽으로 끌면 적재, 문서를 왼쪽으로 끌면 게시 대화상자가 열립니다. 한쪽 머리를 눌러 접을 수 있습니다.

📰 피드 RSS · Atom · JSON Feed 구독은 계정의 1차 수집입니다 (제안). 상호작용 대상이 없으므로 공유는 링크 글이 됩니다. 같은 출처가 ActivityPub을 제공하면 팔로우로 전환을 권합니다. 팔로우 중인 액터의 RSS는 같은 URL로 합칩니다. 기본 목표는 TT-RSS 구독 목록을 OPML로 옮겨 오는 것입니다 (⇅ OPML). 피드는 single 모드에서도 동작합니다. 자동 적재 규칙은 후속 제안입니다.

모든 안에 공통: Ctrl+K 명령 팔레트, ⇄ 흐름 기록, 게시물과 문서 사이의 교차 링크.

RD12 A: 계정 트리에 네이티브 액터 하나. B: 연결한 Mastodon·Bluesky 계정이 같은 트리에 들어오고, 통합 홈은 같은 게시물을 한 번만 보입니다. 글쓰기에서 보낼 계정을 고릅니다.
