📖 리더 및 FlatList 레이아웃 환경설정

Tiny Tiny RSS 스타일의 한 줄 FlatList 모드와 3단 분할 뷰, 그리고 하나의 컨텐트 뷰 안에서의 수집 원문 ⇄ 적재 본문 기본 전환 동작을 제어합니다. 변경 사항은 즉시 저장되어 /syndication 리더에 반영됩니다.

기본 목록 표시 형태 (List Style) 한 줄 FlatList는 모든 메타데이터를 34px 단일 행 테이블로 나열하며, 상세 카드는 초기 프로토타입처럼 다단 행에 제목, 본문 미리보기, 태그 칩, 빠른 적재/발행 버튼을 카드 형태로 풍부하게 노출합니다.
기본 화면 분할 구조 (UI Layout) 3단 분할 뷰는 좌측 트리 | 중앙 목록 | 우측 전용 리더 창으로 구성되며, 2단 상하 분할 뷰는 좌측 트리 | 상단 목록 / 하단 리더 창으로 구성됩니다.
제목과 작성자 우측의 남는 가로 영역에 — 본문 첫 문장 미리보기를 말줄임표와 함께 아름답게 배치합니다.
컨텐트 뷰 초기 표시 탭 (수집 원문 vs 적재 본문) 하나의 수집 항목이 수집 원문과 적재 본문을 모두 보유할 때 리더가 우선 노출할 본문 탭을 지정합니다.
리더 본문 서체 (Typography) 긴 아티클 정독을 위한 본문 기본 서체(Noto Sans KR 고딕 / Noto Serif KR 명조)를 선택합니다.
리더 기본 글자 크기 (Font Size) .doc-content 본문 영역의 기본 글자 크기(13px ~ 20px)를 지정합니다.
FlatList 행을 클릭해 본문을 펼치거나 j/k 단축키로 이동할 때 안읽음 표시를 자동 해제합니다.

📡 정기 수집 대상 및 카테고리 폴더 관리

선택한 테마 DB에 연결된 RSS/Atom, ActivityPub(Fediverse), AT Protocol 수집 대상과 폴링 주기를 관리합니다.

프로토콜 카테고리 폴더 수집 대상 이름 식별자 / 피드 URI 수집 주기 상태

🏷️ 수집 태그 → 적재 시 엔티티 승격 및 생성 정책 (Tags → Ingested Entities)

수집 시점의 피드 태그는 외부 메타데이터이며, 온톨로지 엔티티는 '적재(Ingestion)'가 수행될 때 비로소 생성 및 해결됩니다. 클레어바이블 지식 그래프에서 태그는 곧 엔티티(entities 노드)이므로, RSS <category>, Atom term, ActivityPub Hashtag, AT Protocol facets에서 수집된 외부 태그는 적재 시점에 프로젝트 적재 정책([태그] 메타데이터 섹션 주입 및 Entity Resolution)에 따라 테마 DB의 엔티티로 정규화·생성·연결됩니다.

RSS/Atom/AP/AT 원문이 제시한 태그를 테마 DB의 기존 entities.norm_name 및 aliases와 대조해 동일 엔티티로 연결합니다.
테마 DB에 아직 없는 태그라도 적재 시 온톨로지 엔티티 후보로 생성하여 지식 그래프 탐색 및 추후 병합(Dedup) 대상에 포함합니다.
[[KV Cache]] → #KVCache 형태로 변환하여 연합우주 검색성을 높입니다.
RSS 피드에서 흔히 유입되는 의미 없는 일반 분류어(예: uncategorized, general)가 온톨로지 엔티티를 오염시키지 않도록 적재 전 필터링합니다.
프로토콜별 태그 수집 필드 ↔ Claire 엔티티 매핑 명세 보기
• RSS 2.0 / Atom 1.0: <category>, <dc:subject> → 적재 원문 상단 [태그] 섹션 병합 → entities 정규화
• ActivityPub (AP): object.tag[type="Hashtag"].name (# 접두사 제거 후 정규화) → entities 정규화
• AT Protocol: app.bsky.richtext.facet#tag 및 레코드 tags[] → entities 정규화
• 리더 하단 태그 바 조작: 미적재 원문 상태에서는 🏷️ 수집 태그 (#Tag)로 관리되며, 적재하기 실행 시 온톨로지 엔티티 [[Entity]]로 승격되어 적재 본문에 귀속됩니다.

⚡ 테마 DB 기반 오거나이즈 · 자동 적재 규칙

정기 수집된 컨텐트를 테마 SQLite DB의 엔티티 연관도(Affinity Score)로 채점하고, 임계치 이상인 항목을 프로젝트 적재 파이프라인으로 자동 전달합니다.

피드의 자동 적재 옵션이 켜져 있을 때, 엔티티·규칙 합산 점수가 이 기준 이상이면 즉시 POST /ingest 적재 큐로 전달합니다.

🔁 RSS/ATOM/AP 부스트·인용 발행 및 적재 본문 발행 정책

RSS/ATOM 컨텐트 역시 단순 원문 열람에 그치지 않고 부스트/인용 발행(Boost / Quote)과 적재 발행(Ingested Body Publish) 두 가지 방식을 모두 지원합니다.

현재 테마 발신 ActivityPub 액터 테마 공개 정책에 따라 외부 연합우주 발신 가능 여부가 결정됩니다.
RSS / ATOM 항목 발행 대화상자 기본 모드 RSS/ATOM 기사에서 발행 버튼을 눌렀을 때 기본으로 선택될 발행 모드를 지정합니다 (대화상자 안에서 언제든 두 모드 간 전환 가능).
ActivityPub 항목 발행 대화상자 기본 모드 원격 Fediverse 포스트에서 발행 버튼을 눌렀을 때 기본으로 선택될 모드입니다.
연합우주 팔로워가 클릭 시 Claire의 정제된 지식 그래프 공유 문서 뷰어로 이동할 수 있도록 합니다.
사용 가능 치환자: {{title}}, {{url}}, {{author}}, {{hashtags}}

📦 OPML 구독 목록 입출력 및 소각 툼스톤 방어벽 진단

기존 Tiny Tiny RSS / FreshRSS / NetNewsWire 등에서 사용하던 OPML 2.0 파일과 호환되며, 소각된 문서의 재수집을 막는 purged_tombstones 방어벽 상태를 점검합니다.
