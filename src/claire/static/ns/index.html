Claire Bible vocabulary

Claire Bible servers use these terms when they exchange shared knowledge with ActivityPub. The terms are for Claire Bible only.

Namespace: https://w3id.org/claire-bible/ns# (prefix claire). JSON-LD context: https://w3id.org/claire-bible/ns/v1. The context of version 1 does not change. A new term goes to a new version.

A document uses this context together with the ActivityStreams context https://www.w3.org/ns/activitystreams. The terms Grant, Revoke, and capability have the identifiers of the ForgeFed vocabulary (https://forgefed.org/ns#). Claire Bible claims no conformance to ForgeFed.

Types

TermIdentifierBase typeDefinition
claire:KnowledgeBasehttps://w3id.org/claire-bible/ns#KnowledgeBaseGroupA shared knowledge base: a knowledge base that has no owner, that is always public, and that accounts build together. It is an actor. Servers that hold copies of its documents follow it.
claire:Extractionhttps://w3id.org/claire-bible/ns#ExtractionObjectThe entities and the relations that a server found in one document. A receiver builds its graph from them and does not send the document to a language model.
claire:Contributionhttps://w3id.org/claire-bible/ns#ContributionObjectOne document with its extraction that an account offers to one shared knowledge base.
Granthttps://forgefed.org/ns#GrantActivityAn activity that gives a role in a resource to an actor until an end time. The term is the one of the ForgeFed vocabulary. In Claire, a shared knowledge base gives the role claire:collaborator to an account of another server.
Revokehttps://forgefed.org/ns#RevokeActivityAn activity that ends a grant immediately. The term is the one of the ForgeFed vocabulary.

Properties

TermIdentifierDefinition
claire:knowledgeTypehttps://w3id.org/claire-bible/ns#knowledgeTypeThe knowledge type of a shared knowledge base: "real" for knowledge about the real world, or "fictional" for knowledge about an invented world.
claire:documentCounthttps://w3id.org/claire-bible/ns#documentCountThe number of visible documents in a shared knowledge base.
claire:entityCounthttps://w3id.org/claire-bible/ns#entityCountThe number of entities in a shared knowledge base.
claire:relationCounthttps://w3id.org/claire-bible/ns#relationCountThe number of relations in a shared knowledge base.
claire:signaturehttps://w3id.org/claire-bible/ns#signatureThe subject signature of a shared knowledge base, as one JSON value. The key "entities" has at most 256 rows [type, norm_name, weight]: the entities that the most documents have. The key "visible_documents" is the number of documents that were counted. The key "computed_at" is the time of the calculation. A server compares signatures to put knowledge bases with the same subject in one theme.
claire:documentshttps://w3id.org/claire-bible/ns#documentsThe collection of the documents of a shared knowledge base.
claire:contentHashhttps://w3id.org/claire-bible/ns#contentHashThe SHA-256 of the source text of a document, as 64 lowercase hexadecimal characters. A different value for the same document is a revision.
claire:roothttps://w3id.org/claire-bible/ns#rootThe root document: the document from which a chain of copies started. Revisions come from it. A root document refers to itself.
claire:extractionhttps://w3id.org/claire-bible/ns#extractionThe extraction of a document.
claire:keyClaimshttps://w3id.org/claire-bible/ns#keyClaimsThe main statements of a document, as plain text, in sequence.
claire:entitieshttps://w3id.org/claire-bible/ns#entitiesThe entities of an extraction, as one JSON array. Each entity has the keys "name", "type", "norm_name" (the name in its normal form; "type" and "norm_name" together are the key of the entity), "aliases", and "observations". The key "sameAs" is optional: identifiers of the same thing at an authority, for example "wd:Q42" (Wikidata), an ISBN, or an ORCID. The key "proposed_type" is optional.
claire:relationshttps://w3id.org/claire-bible/ns#relationsThe relations of an extraction, as one JSON array. Each relation has the keys "source" and "target" (each one the "name" of an entity of the same extraction) and "type". The key "proposed_type" is optional.
claire:documenthttps://w3id.org/claire-bible/ns#documentThe document of a contribution.
claire:reasonCodehttps://w3id.org/claire-bible/ns#reasonCodeThe reason of the reviewers for a rejection or a removal: "off_subject", "wrong_knowledge_type", "duplicate", "low_quality", "spam", or "other". A rejection of an automatic contribution can also have "automatic_not_accepted": the server of the knowledge base accepts no automatic contributions now.
claire:automatichttps://w3id.org/claire-bible/ns#automatictrue in a contribution that the automatic rule of the account selected. A server that accepts no automatic contributions rejects such a contribution. A contribution without this term is one that the account selected itself.
claire:acceptsAutomatichttps://w3id.org/claire-bible/ns#acceptsAutomatictrue when the server of a shared knowledge base accepts automatic contributions now, false when it rejects them. A server reads it before it sends an automatic contribution.
capabilityhttps://forgefed.org/ns#capabilityThe grant that permits an activity. The term is the one of the ForgeFed vocabulary. In Claire, an offer of a remote collaborator refers to its grant.

Values

TermIdentifierDefinition
claire:collaboratorhttps://w3id.org/claire-bible/ns#collaboratorThe role of an account whose contributions to a shared knowledge base need no approval.
